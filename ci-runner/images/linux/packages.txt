# The toolset of the ubuntu-24.04 machine image, read by build.sh. One tool
# a line: `<source> <name> <version> [<sha256 x86_64> <sha256 aarch64>]`.
#
#   apt      From Ubuntu 24.04 (noble, main and universe) as the archive
#            snapshot build.sh pins had it; version is `-`, the snapshot
#            decides it, and apt checks every package against the
#            archive's signed index.
#   docker   From Docker's apt repository for noble, at exactly this
#            version; apt checks it against Docker's signed index, whose
#            key build.sh pins by fingerprint.
#   release  A release archive or binary from its publisher, checked
#            against the sha256 here (taken from the publisher's own
#            checksum list or release digest). build.sh knows each name's
#            URL and where it goes.
#   rust     A Rust toolchain rustup installs (rustup checks each component
#            against the channel manifest's sha256).
#
# A changed line is a new image version; nothing here is fetched as
# "latest".
