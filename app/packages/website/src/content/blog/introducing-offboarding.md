Removing someone from the team is one item on the list. Someone still needs to check whether they own a resource, hold a paid seat, or are scheduled for next week's on-call rotation. Those jobs can fall to different people and take more than an afternoon.

**Offboarding** gives that work a saved checklist in Infrawrench. Open it on web or desktop and start with the person's email address. Add any handles or old addresses they used so the checklist can look for those too.

![The Infrawrench Offboarding checklist with example data, showing progress and matches to review](https://agent-assets.infrawrench.com/docs-screenshots/features/offboarding/checklist.png)

## Review what turns up

The checklist uses data already synced from your connected accounts. Each row shows why it matched. An exact email match is different from a shared name: confirm a possible match before acting on it, or set it aside if it belongs to someone else.

Work through rows as you go. For example, reassign an upcoming on-call slot, transfer ownership of a resource, or review a paid seat. Where a connected provider supports an action, the row offers it. If you handle a row in the provider's own console, mark it done when you come back.

## Leave a record for the next person

You can close the tab and return to the same checklist later. If you've synced the accounts again or added another alias, rescan. When the work is finished, export a CSV showing what the checklist found and how each row was handled.

To try it, open **Offboarding** in Infrawrench on web or desktop, or start from **Settings → Team**. See the [Offboarding docs](/docs/features/offboarding) for coverage and what to check separately.
