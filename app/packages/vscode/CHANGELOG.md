# Changelog

## 0.2.0

- `.infraenv` language: syntax highlighting, comments, brackets.
- `.infraenv` problems: syntax as you type, and references that point at nothing when signed in.
- Hover on a `.infraenv` reference: the resource or secret it resolves to, per environment.
- Commands: Check .infraenv, Pull .env, Insert Resource Reference.

## 0.1.0

- Terraform hover and CodeLens: live resource, drift, owning service, 30-day cost, estimate, posture findings.
- Working-tree cost estimate through the pull request check preview.
- Command palette search over resources, workflows and services.
- Services view.
- Browser or API key sign-in, organization picker.
